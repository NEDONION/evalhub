# 前端侧边栏页面分区实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将饱和的单页控制台拆为四个由侧边栏导航的任务视图，并在视图切换时保留所有异步任务和表单状态。

**Architecture:** `App` 保持唯一状态所有者，通过本地 `WorkspaceView` 状态决定渲染哪一组现有面板。新增纯展示的 `SidebarNav` 与 `OverviewPanel`，不引入路由依赖，也不移动 `useEvalHub` 的网络和轮询逻辑。

**Tech Stack:** React 19、TypeScript、Tailwind CSS 4、Lucide React、Vitest、Testing Library

## Global Constraints

- 桌面端使用左侧目录，移动端使用横向可滚动目录。
- 目录切换不得清除模型下载、Benchmark 更新、评测结果或表单选择。
- 默认视图必须是“概览”，评测成功后自动进入“评测结果”。
- 不新增前端路由依赖。
- 所有按钮必须具有可访问名称，活动项使用 `aria-current="page"`。
