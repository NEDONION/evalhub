# 文档日期中文命名实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 `docs` 中除固定导航入口外的 Markdown 文档统一为 `YYYYMMDD_中文标题.md`，并保证仓库内引用全部有效。

**Architecture:** 保留现有分类目录，只修改文件名和引用。日期沿用原始创建日期，标题使用中文并保留必要技术名词；`docs/README.md` 是唯一例外。

**Tech Stack:** Markdown、Git、ripgrep、Node.js 本地链接检查、Mermaid CLI。

## Global Constraints

- 不移动或改名 `docs/README.md`。
- 不修改 `scripts/`、`src/`、`tests/` 中的并发业务改动。
- 不改变文档正文语义，只更新命名规则、链接与路径引用。
- 所有新文件名不得包含空格。
- 所有生效中的 Markdown 链接和当前路径引用必须清除旧路径；历史迁移记录可以明确标注并保留当时的旧路径。
