# Agent 模型推荐目录实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用五个不超过 5 GB 的工具型模型替换 Ollama 推荐目录，并统一控制台、服务端和 CLI 默认模型。

**Architecture:** 继续由 `evalhub.ollama.RECOMMENDED_OLLAMA_MODELS` 提供唯一推荐目录，API 沿用现有已安装模型优先合并逻辑，React 只消费现有 `model_options`。不新增接口、组件或依赖。

**Tech Stack:** Python 3.11、unittest/pytest、React 19、TypeScript、Vitest、Ollama。

## Global Constraints

- 推荐目录固定为 5 个模型，每个预估下载大小不超过 5,000,000,000 字节。
- 首次默认模型固定为 `granite4.1:3b`。
- 已安装但不在推荐目录中的模型仍保留并排在推荐项之前。
- 新增或修改的 Python 方法保持详细中文 docstring 与中文逻辑注释。
- 不新增依赖，不下载模型，不修改下拉框布局。

```python
def test_recommended_catalog_contains_five_small_agent_models(self) -> None:
    """推荐目录应固定为五个不超过 5 GB 的工具型 Agent 模型。"""
    from evalhub.ollama import DEFAULT_OLLAMA_MODEL, RECOMMENDED_OLLAMA_MODELS

    # 名称、顺序和预估容量共同构成控制台下拉框的稳定目录契约。
    catalog = [
        (item["name"], item["estimated_size_bytes"])
        for item in RECOMMENDED_OLLAMA_MODELS
    ]
    self.assertEqual(DEFAULT_OLLAMA_MODEL, "granite4.1:3b")
    self.assertEqual(
        catalog,
        [
            ("granite4.1:3b", 2_100_000_000),
            ("qwen2.5-coder:7b", 4_700_000_000),
            ("granite3.3:8b", 4_900_000_000),
            ("phi4-mini:3.8b", 2_500_000_000),
            ("llama3.2:3b", 2_000_000_000),
        ],
    )
```
