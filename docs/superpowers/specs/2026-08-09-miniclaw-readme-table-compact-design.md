# MiniClaw README 主表紧凑化设计

## 目标

缩窄 README 中 `MiniClaw Agent Evaluation Report` 的正式结果主表，使其在常见单页宽度下
更容易阅读，同时保留模型结果、协议和执行效率数据。

## 已确认方案

- 删除主表的 `Job ID` 列及三行对应单元格。
- 保留完整模型名，不使用 `V4 Pro`、`V4 Flash` 等缩写。
- 保留运行方式、协议预检、通过样例、失败样例、工具调用/错误和平均耗时字段。
- 不改动表格下方说明、六维结果、Pi 对照、排除运行或任何评测数值。

## 验证

- 检查 Markdown 表头、分隔行和三行数据具有相同列数。
- 运行 `git diff --check`，确认没有空白错误。
- 检查 README 相关段落，确认只删除正式结果主表中的 Job ID。
