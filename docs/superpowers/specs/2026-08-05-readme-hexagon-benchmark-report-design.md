# README 六边形模型评测报告设计

## 目标

把 2026-08-05 实际完成的 11 个模型、330 个样本的 `evalhub-hexagon-v1`
1.2.0 评测结果直接展示在仓库根 `README.md`，让 GitHub 访客无需启动 EvalHub
即可比较总体成绩和六维能力画像。

## 展示方案

在 README 的界面预览之后增加“Model Benchmark Report”章节，依次包含：

1. 评测口径：Suite 版本、固定 30 个样本、运行日期和执行环境。
2. 总榜：模型、运行方式、通过样本数与平均分。
3. 六维成绩表：知识、指令遵循、数学、综合推理、代码和安全可信，统一使用
   0–100 分。
4. 六边形小多图：11 个模型使用相同轴顺序和比例，避免把 11 条曲线叠在一张图上。
5. 可比性说明：同一题集下存在普通 Ollama、`think=false` Ollama 和
   OpenAI-compatible 三类生成协议指纹，跨组结果可观察但不表述为严格同协议排名。

## 文件与数据流

只修改两个交付文件：

- `README.md`：写入完整报告、表格、说明和静态图片引用。
- `docs/assets/hexagon-model-comparison.svg`：保存 GitHub 可直接渲染的六边形小多图。

数据来自本轮 11 个状态为 `success` 的 EvalHub 持久化任务。SVG 为本轮结果的静态快照，
不新增运行时依赖、生成脚本、前端逻辑或 CI 自动更新。

## 视觉规则

- 11 个面板共用 0–100 刻度、六条轴和轴顺序。
- 使用浅色背景、深色文字、蓝色描边和半透明填充，保证 GitHub 明暗主题下可读。
- 每个面板展示模型名和总体分；正文表格保留精确分数，图形只承担形状比较。
- SVG 提供英文 `aria-label`，README 图片提供描述性 `alt`。

## 验证

交付前执行：

- 对照 11 个任务详情复核总分、通过数和六维分数。
- 解析 SVG XML，并渲染检查模型标题、闭合多边形和统一坐标。
- 检查 README 图片路径和 Markdown 表格。
- 运行 `git diff --check`、Ruff 和 pytest；本次不改变运行时代码。

## 非目标

- 不增加动态排行榜服务或 README 自动发布流水线。
- 不把 30 题 Mini Suite 成绩描述为上游 Benchmark 官方完整榜单。
- 不改变现有 Model performance 页面和评测协议。
